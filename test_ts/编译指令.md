arm-linux-gnueabihf-gcc \
-I /home/zr-arm/tools/tslib/include \
-L /home/zr-arm/tools/tslib/lib \
-l ts \
-o ts_read ts_read.c

arm-linux-gnueabihf-gcc：ARM 交叉编译器，用于生成适合 ARM 设备运行的程序。
-I：指定头文件目录，解决 tslib.h 的包含问题。
-L：指定库文件目录，解决 libts 的查找问题。
-lts：链接 tslib 库，程序才能调用触摸屏接口。
ts_read.c：源文件。
-o ts_read：生成输出文件 ts_read。


注：
for (int i = ...) 在 C99 才被允许。使用-std=gnu99可以启用C99
